User Story 3_2: Modify Selected Courses

As a student, I want to remove a previously selected course before generating my timetable so that I can adjust my course selections without restarting the registration process.

Acceptance Criteria
The system allows the student to remove a previously selected course by entering its course number.
The system verifies that the entered course exists in the current selected course list.
The system displays an appropriate error message if the student attempts to remove a course that has not been selected.
Once a course is successfully removed, it no longer appears in the selected course list.
After removing a course, the student may select another valid course before proceeding to timetable generation.
The updated selected course information is returned and remains available for the schedule generation module.
