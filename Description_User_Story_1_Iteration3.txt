# User Story 1 - Course Count Validation

## Description

As a student,  
I want to enter the number of courses I plan to register for,  
So that the scheduling system knows how many courses I need.

For Iteration 3, this user story focuses on validating the number of courses entered by the user. The system should make sure that the course count is a valid positive integer and that the user cannot enter more courses than the number of offered courses.

This feature helps prevent invalid schedule requests before the course selection and scheduling process begins.

---

## Acceptance Criteria

1. The system accepts a valid positive integer as the number of courses.
2. The system rejects zero as an invalid course count.
3. The system rejects negative numbers as invalid course counts.
4. The system rejects non-integer input.
5. The system rejects a course count that is greater than the number of offered courses.

---

## Implementation Plan

This feature is implemented using a `CourseCountValidator` class.

The validator receives a list of available course numbers and checks whether the number entered by the user is valid. The course count must be an integer, greater than zero, and less than or equal to the number of available courses.

This keeps the validation logic separate from the rest of the scheduling system and makes the feature easier to test.

---

## Files Added

### `course_count_validator.py`

This file contains the `CourseCountValidator` class.

Main responsibilities:

- Store the available course list.
- Count how many courses are available.
- Validate the course count entered by the user.
- Raise an error if the input is not valid.

The validator checks that:

- The course count is an integer.
- The course count is greater than zero.
- The course count is not greater than the number of offered courses.

---

### `test_course_count_validator.py`

This file contains unit tests for `CourseCountValidator`.

The tests check:

- A valid course count is accepted.
- Zero is rejected.
- A negative number is rejected.
- Non-integer input is rejected.
- A number greater than the available course count is rejected.

These tests support Test-Driven Development and help verify that the validation logic works correctly.

---
